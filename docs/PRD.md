# PRD: 공공직군 행정업무 슈퍼앱

## 1. 개요

공공직군 행정업무 슈퍼앱은 팀 일정 공유, 엑셀 업무 자동화, 민원 대응 챗봇, 공공 행정 뉴스 수집을 하나의 웹 애플리케이션에서 제공하는 내부 업무 지원 시스템이다.

목표는 반복 행정 업무를 줄이고, 팀 단위 정보 공유를 표준화하며, 민원 대응 품질을 일정 수준 이상으로 유지하는 것이다.

## 2. 사용자

| 사용자 | 설명 | 주요 사용 기능 |
| --- | --- | --- |
| 일반 팀원 | 일정 공유 및 업무 자동화를 사용하는 실무자 | 캘린더, 엑셀 자동화, 뉴스 조회 |
| 팀 관리자 | 팀원 일정과 업무 현황을 관리하는 담당자 | 일정 승인/관리, 전체 캘린더 조회 |
| 민원 담당자 | 민원 응대 문안을 작성하는 담당자 | 민원 대응 챗봇, 매뉴얼 검색 |
| 시스템 관리자 | 계정, 권한, 운영 상태를 관리하는 담당자 | 사용자/권한 관리, 로그 확인 |

## 3. 핵심 기능

### 3.1 팀원 스케줄 관리

팀원들의 휴가, 근무, 출장 등 일정을 공유하는 캘린더 기능을 제공한다.

#### 요구사항

- 사용자는 본인의 일정을 등록, 수정, 삭제할 수 있다.
- 일정 유형은 휴가, 근무, 출장, 교육, 기타로 구분한다.
- 팀 관리자는 전체 팀원의 일정을 월간, 주간, 일간 단위로 조회할 수 있다.
- 일정에는 제목, 일정 유형, 시작일시, 종료일시, 장소, 설명, 공개 범위를 포함한다.
- 휴가 일정은 팀 관리자 승인 상태를 가질 수 있다.
- 같은 시간대의 중복 출장/휴가 현황을 확인할 수 있어야 한다.

#### 우선순위

- MVP: 일정 등록/조회/수정/삭제, 월간 캘린더, 팀원별 필터
- 이후: 승인 워크플로우, 알림, 반복 일정, 공휴일 연동

### 3.2 엑셀 업무 자동화

특정 컬럼 기준으로 엑셀 파일을 나누거나 여러 엑셀 파일을 합치는 기능을 제공한다.

#### 요구사항

- 사용자는 `.xlsx` 파일을 업로드할 수 있다.
- 사용자는 기준 컬럼을 선택해 파일을 여러 개로 분리할 수 있다.
- 사용자는 여러 파일을 업로드해 하나의 파일로 병합할 수 있다.
- 병합 시 헤더 일치 여부를 검증한다.
- 처리 결과 파일은 다운로드할 수 있어야 한다.
- 처리 실패 시 원인 메시지를 제공한다.

#### 우선순위

- MVP: 단일 컬럼 기준 분리, 동일 헤더 파일 병합, 결과 다운로드
- 이후: 다중 조건 분리, 컬럼 매핑, 템플릿 저장, 처리 이력 관리

### 3.3 민원 대응 챗봇

첨부된 민원 매뉴얼을 바탕으로 대응 방식이나 응대 스크립트를 작성해주는 챗봇 기능을 제공한다.

#### 요구사항

- 사용자는 민원 내용을 입력할 수 있다.
- 사용자는 민원 매뉴얼 파일을 첨부하거나 등록된 매뉴얼을 선택할 수 있다.
- 챗봇은 매뉴얼 기반으로 대응 절차와 응대 스크립트를 제안한다.
- 답변에는 참조한 매뉴얼 항목 또는 근거 문서명을 표시해야 한다.
- 매뉴얼에 없는 내용은 추정 답변이 아니라 확인 필요로 표시해야 한다.
- 개인정보, 민감정보, 내부 보안 정보가 포함된 경우 경고를 표시한다.

#### 우선순위

- MVP: 매뉴얼 업로드, 질의응답, 응대 스크립트 초안 생성
- 이후: 문서 검색 인덱스, 답변 근거 하이라이트, 민원 유형 자동 분류

### 3.4 뉴스 기사 수집

공공 행정 관련 뉴스를 매일 아침 수집하고 요약해 제공한다.

#### 요구사항

- 시스템은 매일 지정된 시간에 뉴스를 수집한다.
- 수집 키워드는 공공행정, 지방자치, 민원, 복지, 안전, 예산 등으로 관리한다.
- 사용자는 수집된 기사 목록을 날짜별로 조회할 수 있다.
- 각 기사에는 제목, 언론사, 발행일, URL, 요약, 관련 키워드를 저장한다.
- 중복 기사는 제거한다.
- 저작권 보호를 위해 기사 전문 저장은 피하고 링크와 요약 중심으로 관리한다.

#### 우선순위

- MVP: 키워드 기반 수집, 목록 조회, 링크 저장
- 이후: 자동 요약, 중요도 분류, 이메일/메신저 아침 브리핑

## 4. 비기능 요구사항

### 보안

- 사용자 인증은 필수로 한다.
- 역할 기반 접근 제어를 적용한다.
- 민원 매뉴얼과 엑셀 파일은 업무 목적 외 접근을 제한한다.
- 민감정보는 로그에 남기지 않는다.

### 감사 및 추적

- 로그인, 파일 업로드, 파일 다운로드, 챗봇 질의, 일정 변경 이벤트를 기록한다.
- 운영자는 주요 변경 이력을 조회할 수 있어야 한다.

### 성능

- 일반 조회 API는 1초 이내 응답을 목표로 한다.
- 엑셀 처리는 파일 크기에 따라 비동기 처리로 확장 가능해야 한다.
- 뉴스 수집은 사용자 요청과 분리된 백그라운드 작업으로 처리한다.

### 데이터 보존

- 일정 데이터는 업무 기록 기준에 따라 보존한다.
- 업로드 파일 원본은 정책에 따라 일정 기간 후 삭제할 수 있어야 한다.
- 챗봇 대화 이력은 개인정보 포함 가능성을 고려해 보존 기간을 설정한다.

## 5. MVP 범위

- 민원 매뉴얼 업로드 및 챗봇 응답 초안
- 뉴스 수집 결과 조회

- 고도화된 권한 위임 체계
- 대규모 분산 처리
