# PRD: Public Admin RPA Hub

## 1. 개요

Public Admin RPA Hub는 공공 행정 업무를 보조하기 위한 내부용 RPA 스캐폴드다. 현재 구현은 일정 관리, 엑셀 자동화, 정책 뉴스 수집, 그리고 민원 챗봇용 자리표시 화면을 포함한다.

백엔드는 FastAPI와 SQLite를 사용하고, 프런트엔드는 React + Vite + TypeScript로 구성되어 있다.

## 2. 목표

- 일정과 팀원을 한 화면에서 관리한다.
- 엑셀 파일을 열 기준으로 분리하거나 여러 파일을 병합한다.
- 정책 뉴스를 지정 날짜 기준으로 수집하고 목록으로 확인한다.
- 향후 민원 챗봇과 감사 로그를 붙일 수 있는 구조를 유지한다.

## 3. 사용자

| 사용자 | 역할 |
| --- | --- |
| 일반 사용자 | 일정 조회, 엑셀 작업, 뉴스 수집 실행 |
| 운영 담당자 | 팀원과 일정 관리, 결과 확인 |
| 시스템 관리자 | API 상태와 DB 상태 확인 |

## 4. 현재 제공 기능

### 4.1 일정 관리

- 팀원 등록, 수정, 비활성화
- 일정 생성, 수정, 삭제
- 주간 / 월간 보기 전환
- 특정 팀원 기준 필터링
- 일정 시간 검증 및 활성 팀원 검증

### 4.2 엑셀 자동화

- `.xlsx` 파일의 첫 시트 헤더 읽기
- 선택한 열 기준으로 파일 분리
- 여러 `.xlsx` 파일의 헤더가 같을 때 병합
- 결과 파일 다운로드
- 작업 상태 조회

### 4.3 정책 뉴스 수집

- 지정 날짜의 정책 뉴스를 외부 사이트에서 수집
- 수집 결과를 SQLite에 저장
- 날짜 범위 기준으로 뉴스 목록 조회
- 중복 URL은 갱신 또는 건너뜀
- 매일 오전 9시 KST에 전날 뉴스 자동 수집 시도

### 4.4 민원 챗봇

- 현재는 프런트엔드의 자리표시 화면만 제공
- 백엔드 대화 API는 아직 연결되지 않음

## 5. 비기능 요구

- 로컬 개발 환경에서 바로 실행 가능해야 한다.
- API는 JSON 중심으로 동작해야 한다.
- 업로드 파일과 결과 파일은 `backend/data` 아래에 저장한다.
- 민감한 정보는 로그에 남기지 않는다.

## 6. MVP 범위

- 일정 CRUD
- 팀원 CRUD
- 엑셀 split / merge
- 정책 뉴스 수집 및 조회
- 시스템 상태 조회

## 7. 제외 범위

- 실제 사용자 인증/인가
- 외부 SSO 연동
- 메일, 메신저 자동 발송
- 민원 챗봇의 실제 LLM 응답
- 감사 로그 UI

## 8. 성공 기준

- 프런트엔드에서 주요 화면이 정상 렌더링된다.
- 백엔드 헬스 체크와 DB 상태 확인이 성공한다.
- 일정, 엑셀, 뉴스 흐름이 로컬 환경에서 재현된다.
- 문서와 실제 구현이 같은 기능 범위를 설명한다.
