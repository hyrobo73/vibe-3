Public Admin RPA Hub 문서

일정 관리, 엑셀 자동화, 정책 뉴스 수집, 그리고 민원 챗봇 확장용 구조를 갖춘 로컬 개발용 스캐폴드의 현재 상태를 요약한 문서다.

핵심 기능

일정 관리 팀원 등록과 일정 CRUD, 주간 / 월간 캘린더 조회를 제공한다.
엑셀 자동화 첫 시트 헤더를 읽고 split / merge 작업을 수행한다.
민원 챗봇 현재는 프런트엔드 자리표시 화면이며 백엔드는 준비 단계다.
정책 뉴스 지정 날짜 기준으로 수집하고 목록과 다운로드 링크를 보여준다.

기술 스택

React TypeScript Vite Python FastAPI uv SQLite

MVP 범위

  • 팀원 CRUD와 일정 CRUD
  • 엑셀 split / merge
  • 정책 뉴스 수집과 조회
  • 시스템 상태 확인

현재 경계

  • 인증 / 권한 없음
  • 민원 챗봇 API 없음
  • 감사 로그 UI 없음
  • 배포 설정 없음

구조 개요

Frontend는 frontend/src의 화면 구성과 API 클라이언트를 담당하고, Backend는 backend/app의 모듈별 라우터와 SQLite 저장소를 담당한다. 데이터 파일은 backend/data/app.sqlite3에 생성된다.

실행 순서

  • 의존성 설치
  • 백엔드 기동
  • 프런트엔드 기동
  • 헬스 체크 및 화면 확인
